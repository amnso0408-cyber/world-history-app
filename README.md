# 世界史学習アプリ

JavaScript学習の一環として制作中の、世界史の年号・出来事をクイズ形式で
学習できるWebアプリです。(現在実装中)

## 使用技術
- HTML / CSS / JavaScript

## 主な機能
- チャプター一覧
- 4択クイズ
- 正誤判定・解説表示
- ヒント表示
- メモ保存（localStorage）
  
## 現在の実装状況
- トップページ、チャプター一覧から各ページへの遷移を実装
- 4択クイズ機能を実装
- 正誤判定・解説表示を実装
- ヒント表示を実装
- メモ保存機能を実装
